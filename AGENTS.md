# Alameed Training Center Platform repository instructions

At the start of every repository task, read the current versions of all three references in full before substantive analysis, planning, implementation, or review. This requirement applies throughout the repository, including documentation and small changes.

1. [Project-wide AI engineering governance](docs/governance/PROJECT-WIDE_AI_ENGINEERING_GOVERNANCE.md)
2. [AI engineering operating system](docs/governance/AI_ENGINEERING_OPERATING_SYSTEM.md)
3. [Master design system plan](docs/governance/MASTER_DESIGN_SYSTEM_PLAN.md)

Use the governance document for the task workflow and the operating system for engineering decisions and verification. For UI/UX work, apply relevant guidance from the design plan alongside the existing Alameed Training Center design system. The plan describes T.A Advertising Solution, so treat its product-specific requirements as examples. Use Alameed Training Center's own requirements for branding, business rules, and functionality.

Also follow the `AGENTS.md` files in the directories where you work. Before delivery, verify the affected behavior and report what you checked.

When the owner requests work on the responsive redesign, use the [Arabic UI/UX audit and execution plan](docs/RESPONSIVE_UX_PLAN_AR.md). Start with the requested phase, reproduce its findings on the current revision, and record the results against its acceptance criteria. Implementation begins on the owner's instruction.
